# Agent Rules
- Keep webcam processing local; never upload frames or facial landmarks.
- Ask for camera permission only after explicit user action.
- Support at least three styles, live tracking, stop camera, screenshot, and readable errors.
- Release camera tracks, animation frames, renderer resources, and MediaPipe resources.
- Frontend: React/Vite/Three.js/MediaPipe. Backend: Express/PostgreSQL.
- No authentication, payments, marketplace, or face-shape recommendations in MVP.
- Never commit secrets or personal data.
- Do not claim FPS, accuracy, or usability success without measurements.
- Use only assets with appropriate usage rights; document model attribution/license.
